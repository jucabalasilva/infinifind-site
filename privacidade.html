Política de Privacidade — InfiniFind Music

Data de vigência: 2026-11-09

Site: https://infinifind.app

Contato: contato@infinifind.app

O InfiniFind Music ("o app") é um aplicativo de computador gratuito e de código aberto. Ele ajuda

a encontrar onde comprar ou ouvir as músicas da sua biblioteca do YouTube e mantém uma lista limpa

de links. Esta política explica o que o app faz com os seus dados.

1. Resumo

  • O app roda no seu computador. Ele não possui um servidor próprio que receba os seus dados.
  • Ao entrar com o Google, o app lê suas playlists, vídeos curtidos e títulos de vídeos, apenas para

leitura (permissão youtube.readonly). Ele não consegue alterar a sua conta.

  • O app não vende dados, não exibe anúncios, não usa análises de uso nem rastreamento, e não usa

dados de usuário do Google para treinar modelos de IA.

  • Você pode sair a qualquer momento. Ao sair, o acesso do app é revogado no Google e o token

guardado no seu computador é apagado.

2. Informações acessadas

Ao escolher entrar com o Google, o app pede uma única permissão:

  • https://www.googleapis.com/auth/youtube.readonly: acesso somente leitura aos seus dados do YouTube.

Pela API de dados do YouTube, o app lê:

  • os nomes das suas playlists e dos vídeos delas (IDs, títulos, nomes de canais);
  • os seus vídeos curtidos (quantidade e lista);
  • o nome do seu canal, para mostrar "conectado como";
  • se cada vídeo está disponível, privado, excluído ou bloqueado no seu país.

O app não lê seu histórico, inscrições, comentários, mensagens, e-mails nem outros dados do Google.

Se você não entrar com o Google, ainda pode usar exportações do Google Takeout que você mesmo baixar.

O app lê esses arquivos apenas no seu computador.

3. Uso dos dados

Os dados são usados somente para montar as listas e páginas que você pede: encontrar a loja de cada

música, verificar se o vídeo ainda está disponível e criar os arquivos solicitados. Não são usados

para publicidade, perfil de usuário ou qualquer outra finalidade além dos recursos que você usa.

4. Onde os dados ficam guardados

  • Token de login do Google: guardado no chaveiro do sistema (Keychain no macOS, Gerenciador de

Credenciais no Windows ou Secret Service no Linux), quando disponível. Nunca é enviado ao

desenvolvedor, a páginas da web nem para arquivos gerados.

  • Arquivo de cliente: o arquivo OAuth que você importa fica na pasta de dados do app, legível

apenas pelo seu usuário do sistema.

  • Cache de buscas: títulos, lojas encontradas e resultados de disponibilidade ficam em texto

simples na pasta de cache do sistema (por exemplo ~/Library/Caches/InfiniFindMusic no macOS).

O cache é apagado automaticamente 30 dias depois de criado. Você pode apagá-lo a qualquer momento.

  • Arquivos gerados: as páginas HTML e as listas de texto são salvas onde você escolher.

5. Dados enviados a outros serviços

  • Google (login e API de dados do YouTube): pedidos necessários para ler suas playlists e

verificar a disponibilidade dos vídeos. O tratamento dos dados pelo Google está descrito na

Política de Privacidade do Google.

  • YouTube: quando você não está conectado, o app lê páginas públicas de vídeos para verificar a

disponibilidade, do mesmo modo que um navegador faria.

  • API de busca da iTunes (Apple): o artista e o título de cada música são enviados para achar a

página da música na iTunes Store. Não há conta envolvida.

  • Links de busca nas lojas: o app cria links para páginas de busca (por exemplo Bandcamp, Amazon

Music, Deezer e Spotify). Esses sites recebem a busca somente quando você clica no link.

O app não envia outros dados a nenhum servidor operado pelo desenvolvedor.

6. Dados de usuário do Google e requisitos de uso limitado

O uso e a transferência de informações recebidas de APIs do Google seguem a

Política de Dados do Usuário dos Serviços de API do Google,

incluindo os requisitos de Uso Limitado. Em especial:

  • os dados de usuário do Google são usados somente para oferecer os recursos descritos aqui;
  • não são transferidos a terceiros, exceto quando necessário para esses recursos (as requisições ao

Google e à iTunes acima), para cumprir a lei ou com o seu consentimento;

  • não são usados para publicidade nem para desenvolver ou treinar modelos de IA;
  • pessoas não leem esses dados, salvo com o seu consentimento, por motivos de segurança ou para

cumprir a lei. O desenvolvedor não tem acesso a eles, pois ficam no seu computador.

O app também segue os Termos de Serviço da API de Serviços do YouTube

e os Termos de Serviço do YouTube.

7. Revogar o acesso e apagar os dados

  • No app: clique em Sair. O app revoga o acesso no Google e apaga o token.
  • No Google: você também pode remover o app em https://myaccount.google.com/permissions.
  • No computador: apague o app, a pasta de cache e a pasta de dados. A entrada no chaveiro é

removida ao sair.

8. Crianças

O app não é destinado a crianças menores de 13 anos e não coleta dados delas intencionalmente.

9. Alterações

Se esta política mudar, a nova versão será publicada nesta página e a data de vigência será

atualizada. Mudanças importantes são descritas no changelog do projeto.

10. Código aberto

O código-fonte é público, sob licença MIT, em https://github.com/jucabalasilva/infinifind-music.

Todas as afirmações acima podem ser conferidas no código.
